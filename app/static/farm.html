Comment c'est calculé. On part des équipements +PA rentables à briser (page Brisage), on aplatit leurs recettes jusqu'aux matières premières (ressources sans recette) et on somme les quantités.
Source : Métier = récolte (déduit du type de l'objet : Minerai → Mineur, Bois/Écorce/Racine → Bûcheron, Fleur/Plante → Alchimiste, Poisson → Pêcheur, Céréale → Paysan) — fiable. Butin = tombe d'un monstre. ? = type générique indéterminé.
Où farmer : pour les butins, on utilise en priorité les vraies tables de drop de xixou.io (monstre exact + taux + zones), ingérées dans data/drops.json via scripts/ingest_drops.py. Les chips verts (monstre + %, zones) sont donc fiables ; le taux est celui du serveur de référence xixou (sur ton émulateur il peut différer). Une zone vue via le sniffer porte live. À défaut de drop connu, on retombe sur un rapprochement par nom (chips bleus « zone/monstre », ex. « Pollen de Blop » → Prairie des Blops) — à vérifier. « inconnu — voir wiki » = aucune piste.
À réunir = besoin − stock banque ; Coût achat = à réunir × prix HDV (ce que coûterait l'achat plutôt que le farm). Paramètres mémorisés dans ce navigateur.
