🚀 Démarrage & mises à jour

1

Démarrer l'app (base + API)

Le plus simple : lance DofusCockpit.exe (à la racine du projet) → bouton « Démarrer DB + API ». Sinon, en ligne de commande :

docker compose up -d db api

Pré-requis : Docker Desktop lancé.

2

Lancer la capture réseau une fois, en fond

Via l'exe → bouton « Lancer capture » (choisis ton interface). Sinon, depuis la racine du projet, en PowerShell :

& "C:\Program Files\Wireshark\dumpcap.exe" -i Ethernet -f "tcp port 443" -b duration:5 -b files:50 -w data\live\dofus.pcapng

Pré-requis : Wireshark installé. Laisse la capture tourner pendant que tu joues.

3

En jeu : déclenche les mises à jour

🏦 Ouvre ta banque → l'inventaire se synchronise tout seul (~10 s).

💰 Ouvre l'hôtel de vente et parcours des catégories → les prix marché se remplissent.

4

Vérifie

Les tuiles en haut de cette page se mettent à jour, ou va voir la page Banque. Rien à relancer : tant que la capture tourne, tout se met à jour en continu.

💡 L'exe n'embarque pas Docker ni Wireshark (trop lourds) : il les pilote. Installe-les une fois, puis l'exe fait le reste. Place DofusCockpit.exe à la racine du projet (à côté de docker-compose.yml).
